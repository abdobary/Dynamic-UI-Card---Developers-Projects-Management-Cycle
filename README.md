# Bunyan Real Estate Admin Dashboard

A modern React-based admin dashboard designed for real estate and project management workflows. The application demonstrates component composition, Context API, nested routing, reusable UI components, and responsive dashboard layouts.

## 🚀 Features

* 📊 Dashboard overview with project statistics
* 👥 Users Management section
* 🏗️ Projects Management section
* 🧭 Sidebar navigation with active route highlighting
* 🔄 Nested routing using React Router
* 📝 Reusable table and form components
* 🔔 Notification system UI
* 👤 Admin profile avatar
* 📱 Responsive layout built with Bootstrap
* ⚡ Context API for shared state management

## 🛠️ Tech Stack

* React 19
* React Router DOM 6
* Vite
* Bootstrap 5
* FontAwesome
* CSS Modules
* Context API

## ⚙️ Installation

### Clone Repository

```bash
git clone https://github.com/your-username/bunyan-real-estate-dashboard.git
cd bunyan-real-estate-dashboard
```

### Install Dependencies

```bash
npm install
```

### Start Development Server

```bash
npm run dev
```

Open:

```text
http://localhost:5173
```
